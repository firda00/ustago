## 2023-10-27 - Missing ARIA Labels on Key Interactive Elements
**Learning:** This app heavily relies on icon-only buttons (like `LogOut`, `BarChart3` for admin access, `Send` for messages, and `Trash2` for deleting items). Initially, none of these had `aria-label` attributes, rendering them completely inaccessible to screen reader users, who would only hear "button" rather than the button's actual function. Given the translation setup (`T` component), adding localized `aria-label`s significantly improves the semantic richness of the app.
**Action:** When adding new icon-only buttons, especially those using `lucide-react` icons, always include an `aria-label`. Use the application's translation object (`t`) as the primary label source, with a hardcoded fallback string (e.g., `aria-label={t.logout || "Logout"}`).
