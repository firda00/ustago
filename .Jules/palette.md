## 2024-05-18 - Added ARIA labels and focus states to icon buttons
**Learning:** Found an accessibility issue pattern specific to the `index.tsx` file where several primary icon-only buttons (like "Admin Dashboard", "Go back", "Logout", etc.) completely lacked `aria-label` attributes and focus-visible outlines. The memory noted the app uses a custom translation object `t` (e.g. `t.back`), but caution is required to use existing keys. If hallucinating keys, it can crash the app or evaluate to undefined. Using safe hardcoded strings (or explicitly verifying translation dictionary availability) combined with `focus-visible:ring-2 focus-visible:ring-black outline-none` is a highly effective, safe, low-line-count UX win.
**Action:** Always cross-reference the translation dictionary `INITIAL_TRANSLATIONS` before trying to use localized strings for ARIA labels, or fallback to explicitly hardcoded text. Apply `focus-visible` utilities using targeted string replacement to improve accessibility.
