## 2023-10-24 - [Semantic Navigation]
**Learning:** [The app uses generic 'div' wrappers for main brand logos and some top-level navigation which hinders accessibility, screen readers and proper focus management.]
**Action:** [Always ensure that top-level interactive layout elements, like the main logo acting as a "home" button, use semantic '<button>' tags with accurate 'aria-label' and keyboard focus styling ('focus-visible').]
